# pbrAudioDAW
Welcome to version 0.3.0 of pbrAudioDAW! This release introduces a brand new terminal-based workspace, enhanced Blender integration, powerful new audio processing tools, and major memory and performance fixes.

- **New Terminal Interface**: Work directly from your console using our brand-new Text User Interface (TUI) for managing tracks, commands, and playback.
- **Blender 3D Viewport Controls**: Easily view and interact with audio tools directly inside Blender's 3D viewport.
- **Expanded Audio Processors**: Added new tools for processing modal displacement, audio forces, and acoustic pressure.
- **Improved Performance & Stability**: Resolved out-of-memory crashes during complex audio composition and upgraded the storage engine for faster project loading and saving.
- **Bug Fixes**: Fixed alignment issues between physics events and audio signals, resolved missing dependency errors, and improved overall reliability.
